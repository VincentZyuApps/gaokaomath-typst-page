跨越 1952 年统一高考至今的全国历年高考数学试题现代排版与沉浸式在线题库。

---

## 🚀 本地快速启动

```bash
# 1. 克隆本仓库并进入目录
git clone https://github.com/VincentZyuApps/gaokaomath-typst-page.git
cd gaokaomath-typst-page

# 2. 安装前端依赖
npm install

# 3. 启动沉浸式在线题库（访问 http://localhost:61952/）
npm run dev

# 4. 静态站点构建打包
npm run build
```
