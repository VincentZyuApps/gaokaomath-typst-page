## 二、 核心缺陷深入排查与修复方案

### 1. 单题聚焦视口暗黑模式白底异常
- **缺陷现象**：在暗黑模式下，页面底色和题卡均为暗色，但题卡周围的平移缩放视口（Panzoom Viewport）呈现一块巨大的白色背景，视觉突兀刺眼。
- **根本原因**：`docs/.vitepress/theme/components/ExamViewer.vue` 第 1086 行将 `.panzoom-viewport` 的背景硬编码为浅色 `background: #f8fafc`。
- **修复方案**：
  1. 移除硬编码颜色，采用 VitePress 主题变量 `background-color: var(--vp-c-bg-alt)`，自适应明暗切换；
  2. 叠加 20px 间距的微点阵纹理 `radial-gradient(var(--vp-c-divider) 1px, transparent 1px)`，在暗黑模式下呈现沉浸式数学草稿工程画布；
  3. 同步优化 `.toggle-sol-btn`（解析开关按钮）的深色模式适配样式。

### 2. KaTeX `\circled` 序号宏红字告警
- **缺陷现象**：在 2026 北京卷第 18 题等大量试卷中，题干、选项与答案出现的 `\circled1`、`\circled{2}` 被 KaTeX 渲染为醒目的红色警告字体。
- **根本原因**：LaTeX 序号宏 `\circled` 未内置于 KaTeX 核心。在 `throwOnError: false` 配置下，KaTeX 产生 `Undefined control sequence: \circled` 并将其包裹于 `<span class="katex-error" style="color:#cc0000">`。
- **修复方案**：
  在 `ExamViewer.vue` 的 `renderMath` 与 `cleanMathFormula` 预处理流程中，加入正则字符映射层：
  ```ts
  const CIRCLE_DIGITS: Record<string, string> = {
    '1': '①', '2': '②', '3': '③', '4': '④', '5': '⑤',
    '6': '⑥', '7': '⑦', '8': '⑧', '9': '⑨', '10': '⑩'
  };
  s = s.replace(/\\circled\{?([1-9]|10)\}?/g, (_, num) => CIRCLE_DIGITS[num] || num);
  ```
  KaTeX 原生支持直接渲染 Unicode 字符 `①`~`⑩`，公式内外均不再有红字报错。

## 三、 双轨制 PDF 交付体系详细架构

### 1. 现有 PDF 按钮文案改造
将做题页顶部的通用下载按钮重构为语义明确的高清归档标识：
- **按钮文案**：`🖨️ 离线预编译 PDF (完整字体)`
- **气泡提示 (Tooltip)**：`基于 Typst 离线预编译，已内嵌思源宋体/黑体与数学矢量字库，适合印刷排版与离线永久归档 (~500KB)`。

### 2. 双轨 PDF 技术对比矩阵

| 核心维度 | 轨道 A：离线预编译版（内嵌字体） | 轨道 B：在线极速版（免字体/轻量） |
| :--- | :--- | :--- |
| **构建地点** | 本地 / CI 离线批处理自动化管道 | 客户端浏览器前端实时内存流 |
| **字体策略** | **完整子集化内嵌**（试卷出现的汉字与符号内嵌） | **免打包任何字体**（借用用户系统本地字体库） |
| **单卷体积** | 约 400KB ~ 600KB | 约 30KB ~ 80KB（极致超轻） |
| **渲染耗时** | 0 秒等待，CDN 静态直接拉取 | 100 ~ 200 毫秒即时生成弹出 |
| **设备兼容性** | 任意无字库设备、老旧打印机均 100% 绝对一致 | 现代浏览器矢量保真；极速预览无需网络负担 |
| **服务器成本** | 777 套共占用约 380MB 静态空间 | **0 额外磁盘占用**，不占服务器资源 |
| **核心场景** | 实体试卷 A4 印刷、教师组卷、离线归档收藏 | 随时随地临时出卷、移动端轻量快印、无网导出 |

### 3. 在线“免字体版”落地技术路线
- **推荐方案（浏览器级 A4 矢量打印流）**：
  借助试卷已有的连续流式画卷（KaTeX + SVG 几何图），注入定制 `@media print` 规则：
  1. 打印时自动隐藏所有导航、工具栏、侧边栏和折叠交互控件；
  2. 强制页面适配 A4 双栏/单栏纸张排版，设置 `page-break-inside: avoid` 规避公式跨页断裂；
  3. 点击“⚡ 在线免字体 PDF”直接调用系统级矢量 PDF 导出通道，零带宽、零额外字体包开销。
