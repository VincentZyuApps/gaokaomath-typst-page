# 历年全国高考数学现代化题库建设规划 (20261023.init.plan)

## 1. 终极目标 (Ultimate Vision)
将建国以来所有真实高考数学试卷（1952～2026 年，64 个年份，777 套试卷，16,321 道真题）全部在 VitePress 静态站点中数字化呈现，融合 Typst 现代排版与 Web 交互能力，打造集“全量检索大厅、纯矢量试卷排版、单题聚焦沉浸刷题、原生做题文档、Typst 源码与打印版 PDF 双轨离线下载”于一体的现代化高考数学题库。

---

## 2. 当前已完成工作 (Current Progress)

### 2.1 基础设施与排版管道
- [x] 基于 Typst 构建现代印刷级试卷模版（`exam.typ`）与单题卡片模版（`card.typ`）。
- [x] 编写自动化转换器（`scripts/converter.ts`），攻克 LaTeX 宏语法（`\pm`、简写根号/分式、大写希腊字母等）到 Typst 与 Web 的高精度转译。

### 2.2 全量真题大厅建设
- [x] 扫描上游历年数据源，完成全量 64 个年份、777 套试卷（16,321 道真题）的元数据提取并归档至 `docs/public/papers/registry.json`。
- [x] 开发真题检索大厅（`PaperMatrix.vue`）：
  - 题库全景指示牌（64 年 / 777 套卷 / 16,321 题 / 97.4% 步骤覆盖率）；
  - 即时模糊搜索框（支持年份/省份/卷名/文理模糊匹配）；
  - 六大历史时期切片与分省地区筛选器；
  - 智能分页机制（单页 24 套卡片），杜绝 777 套卡片堆积导致 DOM 卡顿。

### 2.3 双层做题与渲染架构
- [x] **纯矢量渲染层**：完成 2024 年全量卷与 1952 年第一届试卷的整卷高清 SVG 与单题卡片（320+ 张）预编译，支持滚轮无限缩放、键盘切题（`←`/`→`/`Space`）与解析开关。
- [x] **原生交互文档层**：将全量 777 套试卷解耦为按需加载静态 JSON，集成客户端轻量 KaTeX 引擎秒级排版公式；解决 777 个 Markdown 全文本导致 VitePress 构建 OOM 的问题，静态化构建时间缩短至 35 秒。
- [x] **自适应降级控制**：无预编译矢量 SVG 的试卷自动降级进入原生交互文档模式，界面统一、功能完备。

### 2.4 版面布局与离线生态
- [x] **侧边栏全局覆盖**：除首页（layout: home）纯净展示外，大厅、全部试卷、关于等页面均拥有侧边栏；大厅与关于显示题库骨干导航，试卷页按年份动态聚合同年试卷，右侧保留大题目录（TOC）。
- [x] **导航栏极简化**：移除右上角“精选试卷”下拉框，聚焦核心骨架。
- [x] **双按钮下载与首批 PDF 上线**：提供【Typst 源码】与【下载打印版 PDF】双按钮，未就绪按钮严格置灰；首批 203 套整卷印刷级 PDF 已预编译落库。
- [x] **排版缺陷修复**：严格限制题干与选项图尺寸，选项带图自动 2×2 网格，彻底根治天津卷等错位。
