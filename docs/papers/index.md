# 🏛️ 全国历年高考数学真题检索大厅

欢迎来到历年高考数学现代真题库。本站收录自 1952 年中华人民共和国统一高考至今的全部真实考卷，全面采用 **Typst 纯矢量渲染** 与 **三种做题模式（📄 连续试卷 / 🎯 单题聚焦 / 📝 原生文档）**。

::: tip 💡 刷题提示
- 点击试卷卡片上的 **【立即刷题】** 进入试卷沉浸式展台；
- 点击 **【PDF】** 可直接下载由 Typst 原生编译的高清 A4 打印版试卷；
- 在单题聚焦模式下，支持鼠标滚轮无限缩放，键盘方向键 `←` / `→` 切题，`空格` 或 `S` 一键切换解析。
:::
