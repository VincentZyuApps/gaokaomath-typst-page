# 🏛️ 全国历年高考数学真题检索大厅

欢迎来到历年高考数学真题题库大厅。本站收录自 1952 年中华人民共和国第一次全国统一高考至今的全部真实考卷（**共 64 个年份、777 套试卷、16,321 道真题**），支持 **三种刷题模式（📄 连续试卷 / 🎯 单题聚焦 / 📝 原生交互文档）** 与 **全量 Typst 试卷源码下载**。

::: tip 💡 刷题与使用提示
- **在线做题**：点击任意试卷卡片上的 **【立即刷题 🚀】** 即可进入试卷全功能做题展台；
- **试卷源码**：点击 **【Typst 📄】** 可直接下载该试卷由 Typst 排版的现代矢量排版源码；
- **答题技巧**：做题展台支持 `←` / `→` 键切题，`空格` 或 `S` 键一键查看/收起详细解析步骤。
:::
